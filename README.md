# Nail's Design de Cílios

Site institucional para apresentação dos serviços de design de cílios com foco em estética, agendamento e conversão.

## Visão geral

Este projeto foi desenvolvido em HTML, CSS e JavaScript, com estrutura responsiva e foco em um nicho premium para design de cílios e beleza, com um toque suave e feminino.

## Estrutura de arquivos

- `index.html` — estrutura do site e seções solicitadas
- `styles.css` — estilização visual e responsividade
- `script.js` — interação do carrossel, calendário, espaços de agendamento e antes/depois
- `docs/guia-projeto.md` — documentação do projeto e manutenção

## Como executar localmente

1. Abra a pasta do projeto no terminal.
2. Execute o servidor local:

```bash
python -m http.server 8000
```

3. Acesse no navegador:

```text
http://localhost:8000
```

## Conteúdo do site

O site inclui, na ordem definida:

1. Apresentação do produto com efeito fade a cada 5 segundos
2. Card da responsável pelo serviço
3. Três comparações antes/depois
4. Depoimentos com vídeo e nome de cliente
5. Formas de atendimento, incluindo domicílio com taxa extra
6. Calendário de horários disponíveis
7. Formulário de agendamento por dia e hora
8. Formas de pagamento, incluindo crédito com taxa de 10%
